# Contributing

Thanks for your interest in Flowpilot AI.

## Before contributing
1. Read the project README and roadmap.
2. Open an issue to discuss larger changes before starting work.
3. Keep pull requests focused and explain how you tested the change.
4. Never commit API keys, passwords, access tokens, or private user data.

## Development
- Node.js 20 or newer is required.
- Run `npm test` before submitting changes.
- Run `npm start` to start the local API server.

## Project principles
Prefer small, understandable changes. Clearly document features that are planned versus implemented. The current planner is deterministic and does not call an AI provider.
